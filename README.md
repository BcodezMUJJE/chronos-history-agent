## ✨ About Chronos

**Chronos** is an intelligent AI agent specialized in world history. It combines powerful large language models with Retrieval-Augmented Generation (RAG), structured historical datasets, and interactive tools to deliver accurate, contextual, and engaging answers about any period, civilization, or historical theme.

Whether you're a student preparing for exams, a researcher, a teacher, or simply a history enthusiast, Chronos helps you understand not just *what* happened, but *why* it mattered and how events connect across time and geography.

---

## 🎯 Key Features

- **Deep Conversational Knowledge** — Ask complex questions in natural language
- **Interactive Timelines** — Generate dynamic timelines for any topic or era
- **Comparative Analysis** — Compare empires, revolutions, leaders, or economic systems
- **Counterfactual Reasoning** — Explore "What if" scenarios with historical grounding
- **Visualizations** — Maps, charts, historical images, and event illustrations
- **Source Citations** — Every major answer includes reliable references
- **Personalized Learning** — Quizzes, study guides, and progress tracking
- **Multi-language Support** — Respond in the user's preferred language

## 🛠️ Tech Stack

| Layer              | Technology                              |
|--------------------|-----------------------------------------|
| **Backend**        | Python 3.11 + FastAPI                   |
| **AI Framework**   | LangGraph (for agent orchestration)    |
| **RAG / Vector DB**| PostgreSQL + pgvector / Chroma          |
| **Frontend**       | React + TypeScript + Tailwind CSS + shadcn/ui |
| **LLM Integration**| Grok, Claude, GPT-4o, or local models  |
| **Visualization**  | Recharts, Leaflet, D3.js                |
| **Deployment**     | Docker, Vercel, Render / Fly.io         |
